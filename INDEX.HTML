Cybersecurity Analysis

Frontend Demo vs. Real Backend Security

🛡️ Frontend Controls Implemented Here

  • • 3 failed login attempts trigger a temporary 30-second lock.
  • • Math CAPTCHA check before verifying login credentials.
  • • Session check (`sessionStorage`) protects `patient-dashboard.html`.
  • • HTML escaping prevents basic script/HTML injection.
  • • Only the logged-in patient's `userId` record is loaded.

⚡ What Real Hospital Backends Need

  • • Password hashing (bcrypt/Argon2) on server—never plain text or `localStorage`.
  • • Server-issued `HttpOnly` / `Secure` session cookies over HTTPS.
  • • Backend IP/account rate limiting (client locks can be bypassed in DevTools).
  • • Encrypted database, RBAC, audit logs, and healthcare compliance.
